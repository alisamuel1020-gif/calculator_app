# Calculator App

A simple, clean, and responsive web-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations (`+`, `-`, `*`, `/`)
- Decimal point support
- Clear display button
- Real-time expression evaluation
- Error handling (shows "Error" on invalid input)
- Modern dark theme with orange operator buttons
- Fully responsive and centered layout

## Demo

Just open `index.html` in any modern browser.

## Project Structure

```
calculator_app/
├── index.html      # Main HTML structure
├── style.css       # Styling and layout
└── script.js       # Calculator logic
```

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/alisamuel1020-gif/calculator_app.git
   ```
2. Open the project folder
3. Double-click `index.html` or open it with a live server

## Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling & layout (Flexbox + Grid)
- **Vanilla JavaScript** – Logic (no frameworks)

## Notes

- The calculator uses JavaScript’s `eval()` for calculations (simple but not recommended for production apps that handle untrusted input).
- The clear button is currently labeled **"CS"**.
